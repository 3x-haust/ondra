# Reference films

All official uploads, studied frame by frame (contact sheets at 2–10 fps,
ffmpeg scene detection, onset/tempo analysis). Times are mm:ss or seconds.
BPM is measured from audio onsets; genres are inferred, not heard.

## Patterns they share

- **UI is the hero.** Real UI, re-rendered cleanly, cropped tight, one
  control at a time; full window only briefly. 3D, glow, particles support.
- **Small type next to UI, big type only without UI.** 2–8% of frame height
  when UI is on screen; 12–30%+ in no-UI teasers.
- **One accent word per line.**
- **Words become UI** (Canvas word → chip; Stitch Export button → hero pill).
- **Hits on reveals.** The biggest musical hit lands on a logo or result,
  with a short fade toward silence just before.
- **Rhythm curve.** Slow open → held 4–8 s real-UI demo → a speeding word
  list → stop → logo.
- **Anchor word + swapping word** lists many features cheaply.
- For ~25–30 s: hook 2 s → problem 2 s → 3–4 feature beats with one UI
  payoff each (~3 s) → quick run 4–5 s → typed CTA 3 s → logo 2 s.

## Big tech, in detail

**Apple — Introducing Apple Creator Studio** (0:35) https://www.youtube.com/watch?v=ISYIEmQxs2M
117.5 BPM, ~16 hard cuts; changes happen as type transforms on black.
Verb run "Prompt it. / Perform it. / … / Share it." one card per ~1.0 s
(every 2nd beat), each verb styled to demonstrate itself ("Write it." types
then bends along a pen path, "Scrap it." crumples into a trash can,
"Upscale it." gets a before/after wipe). "Make a beat." falls apart into a
working step-sequencer. Dock icon opens an iris mask. App names roll like a
slot machine. Logo letters each in a different app's font, snapping to the
clean lockup in 0.5 s.

**Anthropic — Introducing Claude Design** (1:22) https://www.youtube.com/watch?v=t_LBECIQQqs
143.5 BPM. Cream background, coral accent. A "Design" pill clicked expands
into the prompt box; push-ins on one control at a time; zoom-outs to a wall
of projects. Status chip: spark + italic serif verb changing letter by letter
("Designing…", "Tweaking…"). The prompt box stays still while the world it
describes appears behind it. "Make this a line graph instead?" → bars morph
into a line in place. Plan checklist struck through item by item.

**Linear — Introducing Linear Releases / Linear Agent** (0:30 / 0:55)
https://www.youtube.com/watch?v=6dIwFoQ0eVg · https://www.youtube.com/watch?v=mRql2VJ99gM
One hard cut in 30 s; ambient bed with no beat, the camera move is the
rhythm. Black, greys, white; tiny mono all-caps type (~2%). Redrawn UI as
3D planes with strong perspective, macro opening that reads as abstract art
until the pull-back. Typed, deleted and retyped CTA with a block cursor
("REL▌ → RELEASES▌ → ▌ → AVAILABLE NOW▌") and paired key ticks.

**Figma — Introducing Figma Motion** (1:08) https://www.youtube.com/watch?v=l3HuAYXyOTo
~84 BPM. Opens on a defocused macro, pulls back to the editor. A toggle
switch is the demo object: selected with handles, knob dragged along a
keyframe path, easing curve morphs linear → S, toggle plays. One token
switch re-animates a whole icon set. Section-coded saturated color.
Also: Config 2025 launches (fastest cuts, ~1.4/s) https://www.youtube.com/watch?v=NHodnYFUT_I

**Shopify — Editions Summer '25 Trailer** (0:35) https://www.youtube.com/watch?v=CZqaS7PcjdI
~110 BPM, the loud option. Condensed bold caps (12–15%) rising with stagger;
a wall of hundreds of storefront cards ripples like cloth and settles into a
grid; prompt types, "Fetching analytics…" cards stack in depth; rolling
counter "97 → 150+ UPDATES" before the lockup.

**GitHub — Introducing the Copilot coding agent** (0:50) https://www.youtube.com/watch?v=EPyyyB23NUU
117.5 BPM. "Watch as your Copilot plans / builds / tests": only the last
word swaps, every 2 s (4 beats), on the onsets. Chat input cropped 2–3× while
typing with an image attached, then pull-out as code generates. Small white
sans (~3%), final word arrives grey → white.

**Framer — Framer 3.0** (1:15) https://www.youtube.com/watch?v=6aioEoCdBJw
117.5 BPM low end. Light as transition: a vertical neon bar (like a text
caret) sweeps to reveal UI, bends into a glass square, morphs into the
"Publish" button. Title lines revealed by an anamorphic streak. Finale
collapses to a line → flash → logo. Sound design praised in comments.

**Anthropic — Introducing Claude Opus 5.5** (0:20) https://www.youtube.com/watch?v=1f13Bl1sYkw
~110 BPM, 38 cuts in 20 s: one shot per beat, then half-beats, then a dead
stop into calm. Every shot has a dome/horizon edge at the same screen
position (shape-matched cuts); the words stay locked while images cut under.

## Google

**Stitch: Design at the Speed of AI** (1:18) https://www.youtube.com/watch?v=nuJvDXZ9VVU
The closest match for a design tool. Slowest cutting (~0.4/s): text 1.5–2.5 s,
UI 4–8 s. Dark dot-grid canvas, aurora background. Button grows into a modal;
"Generating Screen…" grey card fills with the real design; camera pushes into
a phone's hero image until it fills the frame; pushes into the Export button
until it is a glowing pill, then "Export directly to ___" slot line. Drops at
6.9 s (wordmark forms) and 42.5 s after ~1.5 s of near silence.

**Introducing Canvas in Gemini** (1:00) https://www.youtube.com/watch?v=4Leardp_AGc
~119 BPM, text card / UI shot alternating in 1.3–3 s blocks. Black with an
indigo glow rising from the bottom. UI windows tilted ~30°, blue edge glow.
Word → UI at 13–16 s: pencil underlines "Canvas", a glowing card grows out
of it, shrinks into the real chip in the prompt bar. Glitch decode
"into (`c0d3)" → "into code". Click ripples, hand cursor.

**Build with Google Gemini 2.5** (1:06) https://www.youtube.com/watch?v=qNrQdZF1pLU
Fastest (55+ changes/60 s). Big all-caps titles (~45% of frame for 3 lines),
"SIMULATE ___" anchor, ending "___ ANYTHING" speeding from 0.6 s to
0.1–0.2 s per word, then CTA typed with a blue block cursor.

**A new era of intelligence with Gemini 3** (1:57) https://www.youtube.com/watch?v=98DcoXwGX6I
One continuous camera following a light point along a line; UI on tilted
planes; word carousel with sharp center and blurred neighbours.

**Level up at I/O** (0:27) https://www.youtube.com/watch?v=4JVtVgl8oEs
No UI. Black/white alternating, rainbow-gradient 3D icons; words pinned to
frame corners; "Level up" ×3 at 30% height; scale slams; music stops dead.

**Ready, set, I/O** (0:30) https://www.youtube.com/watch?v=QOIDdIzX9uY
All hard transitions on the 125 BPM grid. One sentence split across worlds;
letters drop into an isometric floor; portal dive into space.

## Reels the user chose (Instagram)

**Gemini UI reel** (the structure "그대로 내용만 바꿔서" was based on):
0–0.3 s full-frame gradient sucked into a star; 0.3–1.3 star spins and
shrinks; 1.3–2.4 star steps left and "Gemini" types letter by letter
(colored letters darken); 2.4–3.3 navy ground, light from below, "Your AI
assistant", slow push; 3.3–4.0 big star covers the frame; 4.0–5.0 search bar
rises, "Ask Google Gemini"; 5.0–6.6 a photo flies in, sticks to the bar, the
border glows, it becomes a thumbnail; 6.6–10 camera rides the typed text big.

**ChatGPT UI reel:** pure black, almost no color; a soft white ring only at
logo/loading. Input → model dropdown → hand-cursor click → spinner → code
window. The only text is text inside the UI.

**Kinetic type reel:** black and off-white only; one gradient mass of
neighbouring hues behind big words ("Every story", "Alive."); "Brands
[image] don't wait." with an image wedged between words (user liked this).
