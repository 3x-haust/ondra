# Reference films

Kinds of product film, broken down from official launch films studied frame
by frame (contact sheets at 2–10 fps, ffmpeg scene detection, onset/tempo
analysis). Times are mm:ss or seconds. BPM is measured from audio onsets;
genres are inferred, not heard. Use these as structures and techniques to
borrow; for a new film, find a few current official launch films of
comparable products and break them down the same way (SKILL.md §1).

## Patterns they share

- **UI is the hero.** Real UI, re-rendered cleanly, cropped tight, one
  control at a time; full window only briefly. 3D, glow, particles support.
- **Small type next to UI, big type only without UI.** 2–8% of frame height
  when UI is on screen; 12–30%+ in no-UI teasers.
- **One accent word per line.**
- **Words become UI** (a word in a title turns into the chip in the prompt
  bar; an Export button grows into the hero pill).
- **Hits on reveals.** The biggest musical hit lands on a logo or result,
  with a short fade toward silence just before.
- **Rhythm curve.** Slow open → held 4–8 s real-UI demo → a speeding word
  list → stop → logo.
- **Anchor word + swapping word** lists many features cheaply.
- For ~25–30 s: hook 2 s → problem 2 s → 3–4 feature beats with one UI
  payoff each (~3 s) → quick run 4–5 s → typed CTA 3 s → logo 2 s.
- **The UI as hero beats an abstract 3D ad**; the input turning into the
  result is usually the strongest moment of the film.

## Film types, in detail

**Verb run as type transforms** (~0:35, ~118 BPM, ~16 hard cuts)
Changes happen as type transforms on black. A verb run ("Prompt it. /
Perform it. / … / Share it.") at one card per ~1.0 s (every 2nd beat), each
verb styled to demonstrate itself ("Write it." types then bends along a pen
path, "Scrap it." crumples into a trash can, "Upscale it." gets a
before/after wipe). A phrase falls apart into a working tool (a step
sequencer). A dock icon opens an iris mask. App names roll like a slot
machine. Logo letters each in a different font, snapping to the clean
lockup in 0.5 s.

**Calm editor demo with a status chip** (~1:20, ~144 BPM)
Warm light background, one warm accent. A pill clicked expands into the
prompt box; push-ins on one control at a time; zoom-outs to a wall of
projects. Status chip: spark + italic serif verb changing letter by letter
("Designing…", "Tweaking…"). The prompt box stays still while the world it
describes appears behind it. "Make this a line graph instead?" → bars morph
into a line in place. Plan checklist struck through item by item.

**Ambient teaser on 3D planes** (0:30–0:55)
One hard cut in 30 s; ambient bed with no beat, the camera move is the
rhythm. Black, greys, white; tiny mono all-caps type (~2%). Redrawn UI as
3D planes with strong perspective, macro opening that reads as abstract art
until the pull-back. Typed, deleted and retyped CTA with a block cursor
("FEAT▌ → FEATURE▌ → ▌ → AVAILABLE NOW▌") and paired key ticks.

**One object as the demo** (~1:10, ~84 BPM)
Opens on a defocused macro, pulls back to the editor. A single small control
(a toggle switch) is the demo object: selected with handles, knob dragged
along a keyframe path, easing curve morphs linear → S, the toggle plays. One
token switch re-animates a whole icon set. Section-coded saturated color.
Event versions of this type cut fastest (~1.4 cuts/s).

**The loud trailer** (~0:35, ~110 BPM)
Condensed bold caps (12–15%) rising with stagger; a wall of hundreds of
cards ripples like cloth and settles into a grid; a prompt types,
"Fetching analytics…" cards stack in depth; a rolling counter
("97 → 150+ UPDATES") before the lockup.

**Anchor sentence, swapping verb** (~0:50, ~118 BPM)
"Watch as it plans / builds / tests": only the last word swaps, every 2 s
(4 beats), on the onsets. Chat input cropped 2–3× while typing with an image
attached, then pull-out as code generates. Small white sans (~3%), final
word arrives grey → white.

**Light as the transition** (~1:15, ~118 BPM, heavy low end)
A vertical neon bar (like a text caret) sweeps to reveal UI, bends into a
glass square, morphs into the "Publish" button. Title lines revealed by an
anamorphic streak. Finale collapses to a line → flash → logo. Sound design
carries much of the effect.

**Beat-per-shot teaser** (~0:20, ~110 BPM, ~38 cuts)
One shot per beat, then half-beats, then a dead stop into calm. Every shot
has a dome/horizon edge at the same screen position (shape-matched cuts);
the words stay locked while images cut under.

**Slow design-tool walkthrough** (~1:20)
Slowest cutting (~0.4/s): text 1.5–2.5 s, UI 4–8 s. Dark dot-grid canvas,
soft aurora background. A button grows into a modal; a "Generating Screen…"
grey card fills with the real design; the camera pushes into a phone's hero
image until it fills the frame, then into the Export button until it is a
glowing pill, then an "Export directly to ___" slot line. Drops at ~7 s (the
wordmark forms) and ~42 s after ~1.5 s of near silence.

**Text card / UI alternation** (~1:00, ~119 BPM)
Text card and UI shot alternate in 1.3–3 s blocks. Black with a cool glow
rising from the bottom. UI windows tilted ~30°, blue edge glow. Word → UI:
a pencil underlines a word in the title, a glowing card grows out of it and
shrinks into the real chip in the prompt bar. Glitch decode
"into (`c0d3)" → "into code". Click ripples, hand cursor.

**Fastest word run** (~1:05)
55+ changes in 60 s. Big all-caps titles (~45% of frame for 3 lines), an
anchor ("SIMULATE ___"), an ending ("___ ANYTHING") speeding from 0.6 s to
0.1–0.2 s per word, then a CTA typed with a block cursor.

**One continuous camera** (~2:00)
The camera follows a light point along a line the whole film; UI on tilted
planes; a word carousel with a sharp center and blurred neighbours.

**No-UI event teaser** (~0:27)
Black/white alternating, gradient 3D icons; words pinned to frame corners;
a two-word slogan three times at 30% height; scale slams; the music stops
dead.

**Hard cuts on the grid** (~0:30, 125 BPM)
All hard transitions on the beat grid. One sentence split across worlds;
letters drop into an isometric floor; a portal dive into space.

## Short vertical reels (9:16)

**Mark-to-prompt UI reel** (~10 s): 0–0.3 s full-frame gradient sucked into
the product's mark; 0.3–1.3 the mark spins and shrinks; 1.3–2.4 it steps
left and the product name types letter by letter (colored letters darken);
2.4–3.3 navy ground, light from below, a short tagline, slow push; 3.3–4.0
a big mark covers the frame; 4.0–5.0 the input bar rises with its
placeholder; 5.0–6.6 a photo flies in, sticks to the bar, the border glows,
it becomes a thumbnail; 6.6–10 the camera rides the typed text big.

**Monochrome UI reel:** pure black, almost no color; a soft white ring only
at logo/loading. Input → model dropdown → hand-cursor click → spinner → code
window. The only text is text inside the UI.

**Kinetic type reel:** black and off-white only; one gradient mass of
neighbouring hues behind big words ("Every story", "Alive."); a sentence
opened around an image ("Brands [image] don't wait.").

## Other approaches worth knowing

- Real UX placed in a tactile 3D space: the "making it" feeling in ~30 s.
- A prompt pill cycling placeholders like a slot machine on white, zero
  hard cuts.
- Restraint: small centered sentence cards, real UI on white.
- An art concept (e.g. oil paintings) composited with live UI.
- A map lifting into an isometric city; icons orbiting an Export button.
- Studio brand films: one design language (grid, type, color) animated as a
  system rather than as a feature tour.
