# Sources

This skill's method draws on, and credits, these public works (see each for its own terms):

- Rikyū (https://rikyu.ai), studied from its public pages on 2026-11-13: the
  idea of splitting logos into geometric marks and wordmarks, starting in one
  colour, named proportion systems (golden, √2, √3, silver) applied to the
  whole mark, its parts or a spiral, construction and outline sheets shown
  with every vector mark, revisions that state what they preserve, few
  variants per request, and applying the mark straight away. Ideas only: no
  text, images or code of Rikyū is copied here.
- Walter Tracy, *Letters of Credit* (1986), and Gunnlaugur SE Briem's notes
  on letter spacing — overshoot, stroke contrast, spacing by area.
- W3C WCAG 2.2 (contrast minimum 1.4.3, non-text contrast 1.4.11) for the
  contrast ratios the scripts measure.
- W3C Web App Manifest (maskable icon safe zone) and Apple's touch-icon size
  for the favicon set.
- Simple Icons (https://simpleicons.org, CC0 data; brand marks belong to
  their owners) through the Iconify API, suggested only as silhouettes for
  the likeness check, never as material.

Libraries the scripts use when present: fontTools (MIT), skia-pathops
(BSD-3-Clause). Fonts named in `references/fonts.md` are under the SIL Open
Font License 1.1 unless noted.
