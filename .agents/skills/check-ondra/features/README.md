# Discord agent checks

Run in this order. Keep the installed bot disconnected during the live pass.

1. [Connection and instructions](connection.md): isolated app, one gateway,
   connected status, personal ways.
2. [Conversation actions](conversation.md): owner input, silent reaction,
   explicit reply, recent history, another person's conversation.
3. [Work and events](work.md): progress, question answers, completion, routines
   and alarms.

Each area records what was exercised. Do not mark another account, a destructive
operation or a model decision as covered by a mock or a state injection.
